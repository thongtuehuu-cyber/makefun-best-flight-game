Sky Courier — Ridge Run is a chase-view flight game written in vanilla JavaScript with no libraries and no network requests. Take the mail plane off the home strip, fly it through ten glowing rings over a valley of patchwork fields, a winding river, a road and a small town, watching fuel, altitude, speed and heading on the lit instrument panel — then bring her down gently on the far strip to deliver the mail. Keyboard (arrows/WASD, Shift/Ctrl throttle) and mouse steering, synthesised engine and chime sounds, and deterministic screenshot scenes.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
